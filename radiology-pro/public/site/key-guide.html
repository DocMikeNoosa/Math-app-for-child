Twój klucz API Claude — krok po kroku

Klucz API działa jak hasło: dzięki niemu RadVox Pro korzysta ze sztucznej inteligencji Claude na Twoim koncie w firmie Anthropic (twórcy Claude). Aplikacja jest dla Ciebie za darmo — Anthropic pobiera tylko opłatę za to, co przygotuje AI, ze środków, które sam wpłacisz. Zajmuje to około 10 minut; najwygodniej na komputerze.

Strona Anthropic jest po angielsku — podajemy dokładne nazwy przycisków (stan: październik 2026; mogą się nieznacznie zmienić).

  1. Załóż konto w Anthropic Otwórz stronę Claude Console i załóż konto (adresem e-mail albo kontem Google). Jeśli przyjdzie e-mail z linkiem — kliknij go. Jeśli strona zapyta o nazwę organizacji, wpisz po prostu swoje imię i nazwisko.
    Otwórz platform.claude.com ↗
  2. Wpłać środki Wejdź w Settings → Billing i kliknij Buy credits. Podaj kartę i wybierz kwotę — na początek wystarczy niewielka. Automatyczne doładowanie (auto-reload) możesz zostawić wyłączone: wtedy nigdy nie wydasz więcej, niż wpłaciłeś.
    Otwórz Billing ↗
  3. Utwórz klucz Wejdź w API keys i kliknij Create key. Wypełnij:
    • nazwa (Name): RadVox
    • ważność (Expiration): Never — ważne! Przy krótszej ważności (np. 30 dni) klucz sam przestanie działać.
    • Workspace: Default (jeśli strona o to pyta)
    • Linked account: zostaw siebie
    i zatwierdź przyciskiem tworzenia klucza.
    Otwórz API keys ↗
  4. Skopiuj klucz Pojawi się długi tekst zaczynający się od sk-ant-. Kliknij Copy (ikona kopiowania). Anthropic pokazuje go tylko raz — jeśli zamkniesz okno za wcześnie, po prostu utwórz nowy klucz.
  5. Wklej go w RadVox Pro Na stronie konta RadVox Pro wklej klucz w pole „Twój klucz API” (Ctrl+V) i kliknij Zapisz klucz. Aplikacja od razu sprawdzi, czy klucz działa, a jeśli nie — napisze, co poprawić. Gotowe, możesz dyktować.
Bezpieczeństwo. Klucz jest jak hasło do Twoich środków w Anthropic — nie wysyłaj go nikomu (także osobie, która Cię zaprosiła), wklejasz go tylko w RadVox Pro. Zapisujemy go zaszyfrowany i nikt nie widzi go w całości. Wydatki sprawdzisz w Anthropic (Settings → Billing); klucz możesz w każdej chwili wyłączyć tam (Disable) albo usunąć z RadVox Pro.

Gdy coś nie działa

  • „Brak środków” — wróć do kroku 2 i doładuj konto.
  • „Klucz jest błędny, wyłączony albo wygasł” — utwórz nowy klucz (krok 3, ważność Never) i wklej go ponownie. Sprawdź, czy skopiowałeś go w całości.
  • „Klucz nie jest przypisany do jednego workspace” — utwórz nowy klucz i wybierz workspace Default.
  • Przycisk Create key jest nieaktywny — konto w Anthropic założył ktoś inny i Twoja rola nie pozwala tworzyć kluczy; poproś tę osobę albo załóż własne konto.
