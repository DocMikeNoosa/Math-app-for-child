    Najpierw: test stanowiska

    Na komputerze, na którym coś nie działa, otwórz Test stanowiska (bez logowania) i kliknij „Uruchom test”. Sprawdza przeglądarkę, połączenie, zegar, mikrofon, rozpoznawanie mowy, schowek i przycisk PowerMic — przy każdym błędzie podaje, co zmienić. Zalogowany radiolog może wysłać wynik — zobaczysz go w zakładce „Problemy i zgłoszenia”. Aplikacja sama zgłasza tam też problemy z mikrofonem, rozpoznawaniem mowy i schowkiem (same kody błędów, bez treści opisów).

    Konta — co możesz zrobić sam(a)

    1. Nowe osoby: „+ Dodaj osobę” lub „Import listy osób” (wklej z Excela: e-mail; imię i nazwisko; PWZ). Hasła tymczasowe są pokazywane tylko raz — pobierz CSV.
    2. Zapomniane hasło: ⋯ → „Nowe hasło tymczasowe” (osoba dostaje też e-mail o zmianie).
    3. Zablokowane logowanie (8 błędnych haseł): ⋯ → „Odblokuj logowanie” — hasło zostaje.
    4. Nowy / zgubiony telefon (logowanie dwuetapowe): ⋯ → „Wyłącz logowanie dwuetapowe”.
    5. Zgubiony laptop, wspólny komputer: ⋯ → wyloguj pojedyncze urządzenie albo wszystkie.
    6. Odejście z firmy: „Zablokuj” (zwalnia miejsce) albo „Usuń” (kasuje dane osobowe).
    7. Każde konto może być zalogowane na 2 urządzeniach naraz; nieużywane urządzenie wylogowuje się po 7 dniach.

    Zapora, proxy, sieć

    • Zezwól na HTTPS (port 443) do adresu .
    • Rozpoznawanie mowy wykonuje przeglądarka u swojego producenta: Chrome — usługi mowy Google, Edge — usługi mowy Microsoft. Gdy test stanowiska pokazuje błąd network, zapora / proxy / inspekcja TLS blokuje ten ruch — dodaj wyjątek dla usług mowy producenta przeglądarki (aktualną listę adresów podaje dokumentacja producenta). Nie przepuszczaj tego ruchu przez inspekcję TLS.
    • VPN o dużych opóźnieniach spowalnia dyktowanie — test pokazuje czas odpowiedzi serwera.

    Zasady przeglądarki (Chrome / Edge, zarządzanie w domenie)

    Gotowe ustawienia, żeby mikrofon, schowek i przycisk PowerMic działały bez pytań. Nazwy zasad są takie same w Chrome i Edge — sprawdź je w dokumentacji zasad Chrome Enterprise / Microsoft Edge przed wdrożeniem w domenie.

    • AudioCaptureAllowedUrls = — mikrofon bez pytania.
    • ClipboardAllowedForUrls = — kopiowanie opisu do RIS.
    • WebHidAllowDevicesForUrls — przycisk mikrofonu: Nuance PowerMic (vendor_id 1364 = 0x0554), Philips SpeechMike (2321 = 0x0911).
    • Upewnij się, że DefaultWebHidGuardSetting nie blokuje WebHID i że adres Radiopis nie jest w WebHidBlockedForUrls, a przeglądarka nie działa w trybie gościa / incognito (ciasteczka muszą być dozwolone).
    
          
    

          
    Przycisk mikrofonu (PowerMic / SpeechMike)
    
          
      
            
    1. W aplikacji: Ustawienia → „Połącz PowerMic” → wybierz mikrofon → „Naucz przycisk” → naciśnij przycisk nagrywania dwa razy. Można włączyć „Przytrzymaj, aby mówić”.
      2. 
            
    2. Jeśli przycisk nie reaguje: Ustawienia → „Diagnostyka mikrofonu” (lub test stanowiska) pokazuje, czy mikrofon w ogóle wysyła dane.
      3. 
            
    3. Brak danych — najczęściej mikrofon przechwytuje inny program (oprogramowanie Nuance PowerMic, Dragon, SpeechMike Control Center). Zamknij go / wyłącz autostart albo zezwól na urządzenie zasadą WebHidAllowDevicesForUrls.
      4. 
            
    4. Podłącz mikrofon bezpośrednio do komputera (nie przez hub), wyłącz oszczędzanie energii USB (selektywne wstrzymywanie USB) — mikrofon nie będzie się „odłączał”.
      5. 
            
    5. Alternatywa zawsze działająca: jeśli oprogramowanie mikrofonu pozwala przypisać przyciskowi klawisz (np. F9), ustaw go, a w aplikacji: Ustawienia → „Klawisz nagrywania” → naciśnij ten przycisk.
      6. 
          
    

          
    Mikrofon w systemie
    
          
      
            
    • Windows → Ustawienia → Prywatność → Mikrofon: dostęp włączony, także dla aplikacji klasycznych (przeglądarka).
      • 
            
    • Windows → Dźwięk → Nagrywanie: właściwy mikrofon jako domyślny, poziom ok. 70–90%, mikrofon niewyciszony.
